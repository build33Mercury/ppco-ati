# Numerical stability and perturbation protocol

No exact/non-identifiability atlas claim is accepted from one arbitrary tolerance.

For each pair report singular values around cutoff, use a pre-specified tolerance grid spanning at least two orders of magnitude, repeat under justified rescaling, quantify projector/residual stability, test scientifically plausible coordinate/resampling perturbations, and return UNKNOWN_NUMERICAL if classification changes inside the admissible range.

Separate digital-operator exactness from biological/scientific equivalence under registration uncertainty.
