# ATI Reference 0.4.0rc7

**Prerelease · Reference software only**

This release provides the ATI numerical-identifiability library, certificates, conditional scalar identified intervals, machine-readable schemas, synthetic examples, software regression tests, and aggregate figure sources for the accompanying functional-connectome atlas-transfer research.

- Preserves the ATI numerical implementation and published-claim boundaries inherited from the earlier reviewed reference code.
- Provides a compact source layout with unique aggregate figure tables, unique tests and one canonical document per retained method topic.
- Documents the separation between conditional operator-specific certificates and full, presently unavailable independent HCP/ABIDE benchmark replay.
- Provides reproducibility instructions, aggregate figure generation and explicit third-party data-rights limitations.

This release is not a clinical tool, a claim of universal atlas recovery, a demonstration of PPCO superiority, or a substitute for participant-level benchmark reproduction. The manuscript has no publication DOI in this release.
